# 运行与部署说明

## 服务端口

| 服务 | 默认端口 | 说明 |
| --- | ---: | --- |
| gateway | 8080 | 统一入口与跨服务路由 |
| backend | 8081 | 认证、用户、题库、练习和考试 |
| judge-service | 8082 | 单选、多选、填空判题 |
| ai-service | 8083 | AI 题目生成与规范化 |
| frontend | Vite 动态端口 | 浏览器访问入口 |

## 必需配置

通过环境变量注入 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD`、`REDIS_HOST`、`JWT_SECRET`、`SERVICE_TOKEN`、`JUDGE_URL`、`AI_URL` 和 `GATEWAY_URL`。`JWT_SECRET` 应至少 32 字节，`SERVICE_TOKEN` 应为随机值。

## 启动顺序

先启动 MySQL 和 Redis，并执行 `sql/ai_exam.sql`。然后启动判题服务、AI 服务、主业务服务、网关，最后启动前端。开发环境可以使用各模块的 `spring-boot:run` 和 `npm run dev`。

## 生产建议

使用反向代理发布前端和网关，限制 8081/8082/8083 只对内部网络开放；为 MySQL、Redis、JWT 和服务令牌使用独立生产配置；部署前运行 Maven 验证和前端构建。
