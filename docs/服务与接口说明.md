# 服务与接口说明

## 请求链路与认证

浏览器 → 网关 → 主业务 → AI / 判题。网关转发 `/api/`、`/ws/` 并提供 `frontend/dist`；不直接路由内部服务。主业务认证由 `common/LoginInterceptor.java` 实现，登录后使用 `Authorization: Bearer <token>`；管理权限由 `@RequireRole("ADMIN")` 标记。具体字段、校验和响应以 DTO 与控制器为准。

| 领域 | 路由示例 | 源码 |
| --- | --- | --- |
| 注册登录 | `POST /api/auth/register`、`POST /api/auth/login` | `AuthController` |
| 用户 | `GET /api/user/me`、`GET /api/user/page`、`PUT /api/user/{id}/role` | `UserController` |
| 分类 | `GET /api/category/list`，分类创建 / 更新 / 删除 | `CategoryController` |
| 题库 | `GET /api/question/page`、`GET /api/question/{id}`、`POST /api/question/{id}/review` | `QuestionController` |
| 练习 / 错题 | `POST /api/practice/submit`、`GET /api/practice/stats`、`GET /api/practice/review`、`PUT /api/wrong/{questionId}/master` | `PracticeController` |
| 收藏 / 点赞 | `POST /api/favor/{questionId}`、`POST /api/thumb/{questionId}` | `InteractController` |
| 考试 | `POST /api/exam/{examId}/start`、`POST /api/exam/answer`、`POST /api/exam/record/{recordId}/submit` | `ExamController` |
| AI | `POST /api/ai/generate`、`GET /api/ai/log/{logId}`、`POST /api/ai/generate/{logId}/confirm` | `AiController` |
| 拓扑 | `GET /api/system/topology`（管理员） | `SystemController` |

上述控制器位于 `backend/src/main/java/com/aiexam/controller/`。

## AI 内部接口

`POST http://127.0.0.1:8083/internal/generate`，请求头 `X-Service-Token`。核心请求字段为 `categoryId`、`type`（SINGLE / MULTI / JUDGE / FILL）、`difficulty`（1–3）、`count`（1–10）、`knowledge`；真实模式还需要 `apiUrl`、`apiKey`、`model`。响应包含 `mode`（DEMO / LIVE）、`questions`、`service`。

业务服务发起异步任务，在 Redis 中暂存结果；管理员确认后入库为待审核题目，审核通过后学生可见。无 API Key 时是固定题目演示；AI 响应会进行格式规范化，不保证题目事实正确，仍需人工审核。

## 判题内部接口

`POST http://127.0.0.1:8082/internal/judge`，请求头 `X-Service-Token`。请求 `items` 是最多 500 项的数组，各项包含 `type`、`answer`、`userAnswer`；响应 `results` 返回逐项 `correct`。

实现位于 `services/judge-service/.../judge/`，支持单选、多选、判断和填空策略；该服务执行题型规则判断，没有运行用户提交的程序代码。
